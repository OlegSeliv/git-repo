## MA_Crossover_EA (MetaTrader 5)

Простой советник для MT5 по пересечению скользящих средних с управлением риском (лот по риску в % от баланса), фиксированными SL/TP и трейлинг-стопом. Подходит для неттинговых счетов (одна позиция по символу); при противоположном сигнале может разворачиваться.

### Файл
- `MQL5/Experts/MA_Crossover_EA.mq5`

### Установка
1. Откройте MT5 → Файл → Открыть каталог данных.
2. Перейдите в `MQL5/Experts` и скопируйте туда файл `MA_Crossover_EA.mq5`.
3. Откройте MetaEditor → найдите файл в дереве → скомпилируйте (F7).
4. В терминале перезапустите список советников или перезапустите MT5.
5. Перетащите советник на график нужного символа/таймфрейма, проверьте входные параметры и включите авто-торговлю.

### Входные параметры (основные)
- **InpSymbol**: символ торговли (по умолчанию текущий график).
- **InpTimeframe**: таймфрейм работы (PERIOD_CURRENT = текущий график).
- **InpFastMAPeriod / InpSlowMAPeriod / InpMAMethod / InpAppliedPrice**: настройки двух МА.
- **InpSLPoints / InpTPPoints**: SL/TP в пунктах (пункты = минимальный шаг цены символа в терминах `SYMBOL_POINT`).
- **InpRiskPercent**: риск на сделку в % от баланса. Если 0 → используется **InpFixedLots**.
- **InpFixedLots**: фиксированный лот, если риск = 0.
- **InpMagicNumber**: магик номер советника.
- **InpAllowLong / InpAllowShort**: разрешение лонгов/шортов.
- **InpReverseOnSignal**: при обратном сигнале закрывать текущую позицию и открывать противоположную.
- **InpOnlyOnePosition**: держать одну позицию по символу.
- **InpTradeOnlyOnNewBar**: вход только на новом баре.
- **InpUseTrailingStop / InpTrailingStartPoints / InpTrailingStepPoints**: трейлинг-стоп.
- **InpDeviationPoints**: допустимое отклонение (slippage) при исполнении.
- **InpOrderComment**: комментарий к сделкам.

### Логика входа
- Сигнал BUY: быстрая МА пересекает медленную снизу вверх (по закрытым барам).
- Сигнал SELL: быстрая МА пересекает медленную сверху вниз (по закрытым барам).
- Сигналы проверяются по новому бару, чтобы избежать повторных входов на одном баре (можно отключить).

### Лот по риску
При ненулевом **InpRiskPercent** лот рассчитывается как `riskMoney / (SL_points * valuePerPointPerLot)`. Стоимость пункта берётся из `SYMBOL_TRADE_TICK_VALUE` и `SYMBOL_TRADE_TICK_SIZE`. Результат нормализуется по `SYMBOL_VOLUME_STEP`/`MIN`/`MAX`.

### Трейлинг-стоп
- Для BUY: когда профит в пунктах ≥ `InpTrailingStartPoints`, SL подтягивается на `InpTrailingStepPoints` пунктов ниже текущей цены (BID).
- Для SELL: симметрично (используется ASK).

### Бэктест
1. Откройте «Тестер стратегий» в MT5.
2. Выберите советник `MA_Crossover_EA`, укажите символ и таймфрейм.
3. Задайте период, депозит, режим моделирования, спред.
4. Запустите тест. Для проверки сигналов можно включить визуальный режим.

### Подсказки
- Рекомендуется начинать с меньших значений риска (например, 0.5–1%).
- Проверьте корректность `InpSLPoints`: если SL слишком мал, лот по риску может стать слишком большим/недоступным брокером.
- На некоторых символах `SYMBOL_TRADE_TICK_VALUE`/`SIZE` отличаются — проверяйте в «Свойствах символа».

### Отказ от ответственности
Торговля на финансовых рынках связана с риском. Используйте советник на демо-счёте перед реальной торговлей.
