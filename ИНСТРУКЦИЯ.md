# 🚀 ПРОСТАЯ ИНСТРУКЦИЯ ПО УСТАНОВКЕ

## 📥 ЧТО НУЖНО СКАЧАТЬ И КАК УСТАНОВИТЬ

### Вариант 1: АВТОМАТИЧЕСКАЯ УСТАНОВКА (РЕКОМЕНДУЕТСЯ)

**1. Скачайте один файл:**
   - `УСТАНОВЩИК.py` - это всё, что нужно!

**2. Запустите установку:**
   - Дважды щелкните на файл `УСТАНОВЩИК.py`
   - ИЛИ откройте командную строку и выполните:
     ```
     python УСТАНОВЩИК.py
     ```

**3. Ждите завершения:**
   - Установщик сам скачает всё необходимое
   - Создаст папку `ContractManagementSystem`
   - Настроит всю систему автоматически

**4. Запускайте систему:**
   - Найдите файл `Запуск системы контрактов.bat`
   - Дважды щелкните по нему
   - Откройте браузер: http://localhost:5000
   - Логин: `admin`, Пароль: `admin123`

---

### Вариант 2: РУЧНАЯ УСТАНОВКА (если автоматическая не работает)

**1. Создайте папку проекта:**
```
mkdir ContractManagementSystem
cd ContractManagementSystem
```

**2. Скачайте все файлы проекта в эту папку:**
   - `app.py` - главное веб-приложение  
   - `database_schema.sql` - схема базы данных
   - `document_generator.py` - генератор документов
   - `document_storage.py` - система хранения
   - `analytics_reporting.py` - аналитика и отчеты
   - `mobile_app.py` - мобильное приложение
   - `windows_app.py` - десктопное приложение
   - `requirements.txt` - зависимости
   - `setup.py` - настройщик
   - Все файлы из папки `templates/` (HTML шаблоны)
   - Все файлы из папки `static/` (CSS, JS)

**3. Установите Python (если нет):**
   - Скачайте с https://python.org (версия 3.8 или выше)
   - При установке обязательно отметьте "Add to PATH"

**4. Установите зависимости:**
```bash
pip install -r requirements.txt
```

**5. Запустите настройку:**
```bash
python setup.py
```

**6. Запустите систему:**
```bash
python app.py
```

## 🎯 СОЗДАНИЕ EXE-ФАЙЛА

### Для создания единого исполняемого файла:

**1. Установите PyInstaller:**
```bash
pip install pyinstaller
```

**2. Создайте EXE:**
```bash
pyinstaller --onefile --name "Система_Контрактов" app.py
```

**3. Найдите готовый EXE:**
   - Файл будет в папке `dist/`
   - Можно запускать без Python!

## 🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Частые проблемы и решения:

**❌ "Python не найден"**
- Установите Python с python.org
- Обязательно отметьте "Add to PATH" при установке

**❌ "Порт 5000 занят"**
- Закройте другие программы, использующие порт 5000
- Или поменяйте порт в файле app.py (строка app.run)

**❌ "Модуль не найден"**
- Выполните: `pip install -r requirements.txt`
- Если не помогает: `pip install flask sqlalchemy pandas`

**❌ "База данных не создается"**
- Проверьте права доступа к папке
- Запустите от имени администратора

**❌ "Браузер не открывается"**
- Откройте любой браузер вручную
- Перейдите на http://localhost:5000
- Проверьте, что система запущена (окно командной строки открыто)

### 📞 Дополнительная помощь:

1. **Проверьте логи** в папке `logs/`
2. **Перезапустите** систему через bat-файл  
3. **Попробуйте другой браузер** (Chrome, Firefox, Edge)
4. **Запустите от администратора** если проблемы с правами
