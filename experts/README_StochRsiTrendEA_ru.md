# StochRsiTrendEA — инструкция по настройке и использованию

Этот советник (EA) для MetaTrader 5 торгует автоматически по следующей логике:
- Фильтр тренда: RSI на H4. Выше 50 — ищем лонги; ниже 50 — ищем шорты.
- Сигнальный таймфрейм: M15. Вход по стохастику:
  - Лонг: %K поднимается снизу и закрепляется выше 25.
  - Шорт: %K опускается сверху и закрепляется ниже 75.
- Стоп-лосс: 2 × ATR(M15) при открытии сделки.
- Сопровождение: трейлинг-стоп по ATR (chandelier), опционально безубыток и частичная фиксация.
- Опционально: выход по стохастику при достижении экстремумов 95 (лонг) / 5 (шорт).
- Оповещение: звуковой сигнал при входе в позицию (настраивается).

Советник полностью автоматический: он сам открывает и сопровождает позиции по заданным правилам. Вам не нужно открывать сделки вручную, но вы можете настраивать параметры.

## Установка
1. Скопируйте файл `StochRsiTrendEA.mq5` в каталог терминала: `MQL5/Experts`.
2. Откройте файл в MetaEditor и скомпилируйте (F7).
3. В MT5 откройте график нужного символа, таймфрейм можно M15 (советник сам использует M15 и H4 для индикаторов).
4. Перетащите советник из Навигатора на график и установите входные параметры.
5. Разрешите algo-trading в MT5 (кнопка «Algo Trading» должна быть включена).

## Основные параметры
- Lot & Magic:
  - `InpLotSize` — размер лота по умолчанию (0.10).
  - `InpMagicNumber` — магик для идентификации ордеров.
  - `InpDeviationPoints` — допустимое проскальзывание в пунктах.

- Тренд и сигналы:
  - `InpRSIPeriod` — период RSI (H4).
  - `InpTrendTimeframe` — таймфрейм тренда (по умолчанию H4).
  - `InpStochKPeriod`, `InpStochDPeriod`, `InpStochSlowing`, `InpStochMaMethod`, `InpStochPrice` — параметры стохастика.
  - `InpSignalTimeframe` — сигнальный ТФ (по умолчанию M15; общий для Stoch и ATR).
  - `InpRSITrendLevel` — порог RSI для направления тренда (50).
  - `InpLongEntryLevel` — уровень стохастика для лонг-входа (25).
  - `InpShortEntryLevel` — уровень стохастика для шорт-входа (75).

- Стоп-лосс и трейлинг:
  - `InpATRPeriod` — период ATR.
  - Базовый SL при входе: 2 × ATR(M15).
  - `InpEnableTrailingStop` — включить трейлинг (true).
  - `InpTrailAtrMult` — множитель ATR для трейлинга (3.0 по умолчанию; меньше — агрессивнее, больше — шире).
  - `InpTrailUseBarClose` — использовать закрытие последнего бара M15 как опорную цену (true) или Bid/Ask.
  - `InpMinTrailStepPoints` — минимальный шаг подтяжки стопа в пунктах.

- Безубыток:
  - `InpEnableBreakeven` — включить перевод в безубыток.
  - `InpBETriggerAtrMult` — триггер срабатывания по профиту в X × ATR.
  - `InpBEOffsetPoints` — на сколько пунктов выставлять SL дальше цены входа.

- Частичная фиксация:
  - `InpEnablePartialClose` — включить частичное закрытие.
  - `InpPartialTriggerAtrMult` — триггер по профиту в X × ATR.
  - `InpPartialClosePercent` — доля закрытия позиции (0..1].
  - `InpPartialMinVolume` — минимальный остаток объема после частичного закрытия.

- Выход по стохастику (опционально):
  - `InpEnableStochExit` — если true, закрываем позицию при достижении стохастиком экстремума: ≥95 (лонг) или ≤5 (шорт).
  - `InpExitLongLevel` / `InpExitShortLevel` — уровни экстремумов (95/5 по умолчанию).

- Звук при входе:
  - `InpEnableEntrySound` — включить звук при входе в позицию.
  - `InpEntrySoundFile` — имя wav-файла (должен быть доступен терминалу MT5 в папке звуков или стандартных ресурсах).

## Рекомендуемые подходы
- Если цель — максимизация прибыли по тренду, оставьте `InpEnableStochExit = false` и полагайтесь на трейлинг/безубыток/частичную фиксацию.
- Для более плотного сопровождения уменьшайте `InpTrailAtrMult` и/или повышайте `InpBETriggerAtrMult`/`InpPartialTriggerAtrMult`.
- Проверяйте брокерский параметр минимального стоп-уровня: советник учитывает его, но слишком агрессивные значения шагов могут блокировать модификации SL.

## Частые вопросы
— Открывает ли советник сделки сам?  
Да. Он полностью автоматический: сам ищет сигналы, открывает и сопровождает позиции.

— Где должен лежать звуковой файл?  
Укажите имя файла в `InpEntrySoundFile` и поместите его в стандартную папку звуков MT5 (например, `Sounds`) или используйте стандартные файлы из поставки MT5.

— Можно ли использовать другой сигнальный таймфрейм?  
Да, `InpSignalTimeframe` — настраиваемый, но логика входов и трейлинга привязана к этому ТФ.

## Журнал и диагностика
Советник пишет ключевые действия в журнал (входы, подтяжка SL, безубыток, частичная фиксация, ошибки модификации). Если что-то пошло не так — пришлите строки журнала, помогу разобраться.
