# 🚀 Быстрый старт

## Запуск за 3 шага

### Windows

1. **Установить Python**
   - Скачать: https://python.org
   - При установке отметить ✅ "Add Python to PATH"

2. **Установить зависимости**
   - Открыть командную строку в папке проекта
   - Выполнить:
   ```cmd
   pip install -r requirements.txt
   ```

3. **Запустить**
   - Двойной клик на `start_windows.bat`
   - Или в командной строке: `start_windows.bat`

### Linux / Mac

1. **Установить зависимости**
   ```bash
   pip3 install -r requirements.txt
   ```

2. **Запустить**
   ```bash
   chmod +x start_linux.sh
   ./start_linux.sh
   ```

### Android (через Termux)

1. **Установить Termux** (из F-Droid)

2. **В Termux выполнить:**
   ```bash
   pkg install python
   pip install fastapi uvicorn
   python backend.py
   ```

3. **Открыть в браузере:** `http://localhost:8000`

## Типичные задачи

### Создать новый контракт
1. Раздел "Контракты"
2. Кнопка "+ Новый контракт"
3. Заполнить форму
4. Сохранить

### Зарегистрировать заказ
1. Раздел "Заказы"
2. Кнопка "+ Новый заказ"
3. Указать контракт, устройство, срок
4. Сохранить

### Проверить дефицит материалов
1. Раздел "Комплектующие"
2. Вкладка "Дефицит"
3. Увидеть список недостающих материалов

### Отправить сотрудника в командировку
1. Раздел "Командировки"
2. Кнопка "+ Новая командировка"
3. Выбрать сотрудника, место, даты
4. Сохранить

### Сгенерировать документ
1. Выбрать заказ
2. Нажать "Сгенерировать акт"
3. Проверить заполненный документ
4. Скачать Word файл

## Решение проблем

**Система не запускается**
- Проверьте установку Python: `python --version`
- Переустановите зависимости: `pip install -r requirements.txt --force-reinstall`

**Порт 8000 занят**
- Измените порт в `backend.py`: `uvicorn.run(app, port=8001)`

**Ошибки при установке библиотек**
- Обновите pip: `python -m pip install --upgrade pip`
