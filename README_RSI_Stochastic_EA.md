# RSI Stochastic Expert Advisor для MetaTrader 5

## Описание стратегии

Торговый робот основан на комбинации индикаторов RSI и Stochastic с использованием двух таймфреймов:

### Логика работы:

1. **Определение тренда (H4):**
   - RSI > 50 → поиск лонг входов
   - RSI < 50 → поиск шорт входов

2. **Условия входа (M15):**
   - **Лонг:** Stochastic поднимается снизу вверх и закрепляется выше уровня 25
   - **Шорт:** Stochastic опускается сверху вниз и закрепляется ниже уровня 75

3. **Управление рисками:**
   - Стоп-лосс: 2 × ATR (M15)
   - Выход из лонга: Stochastic достигает уровня 95
   - Выход из шорта: Stochastic достигает уровня 5

## Параметры настройки

- **LotSize** (0.1) - размер лота по умолчанию
- **RSI_Period** (14) - период RSI
- **Stochastic_K** (5) - период %K стохастика
- **Stochastic_D** (3) - период %D стохастика
- **Stochastic_Slowing** (3) - замедление стохастика
- **ATR_Period** (14) - период ATR
- **ATR_Multiplier** (2.0) - множитель ATR для стоп-лосса
- **MagicNumber** (123456) - магический номер для идентификации сделок

## Установка

1. Скопируйте файл `RSI_Stochastic_EA.mq5` в папку `MQL5/Experts/` вашего MetaTrader 5
2. Скомпилируйте эксперт в MetaEditor
3. Прикрепите к графику с нужными настройками

## Рекомендации

- Тестируйте на исторических данных перед использованием на реальном счете
- Настройте параметры под конкретный инструмент
- Учитывайте спред и комиссии при расчете прибыльности
- Используйте адекватный размер лота для вашего депозита

## Особенности

- Работает только на новых барах M15
- Автоматически закрывает позиции при достижении целевых уровней
- Использует стоп-лосс для ограничения убытков
- Подходит для трендовых рынков
