# Торговый робот для MetaTrader 5

## Описание

Автоматический торговый робот (Expert Advisor) для платформы MetaTrader 5, реализующий стратегию торговли на основе пересечения скользящих средних с расширенными возможностями управления рисками.

## Основные возможности

### 📊 Торговая стратегия
- **Основа стратегии**: Пересечение быстрой и медленной скользящих средних (MA)
- **Сигнал на покупку**: Быстрая MA пересекает медленную MA снизу вверх
- **Сигнал на продажу**: Быстрая MA пересекает медленную MA сверху вниз
- **Настраиваемые параметры MA**: период, метод расчета, применяемая цена

### 💰 Управление капиталом
- Фиксированный размер лота или автоматический расчет по риску
- Максимальный риск на сделку в процентах от баланса
- Ограничение количества одновременно открытых позиций
- Автоматический расчет размера позиции

### 🛡️ Управление рисками
- Stop Loss (стоп-лосс) - ограничение убытков
- Take Profit (тейк-профит) - фиксация прибыли
- Trailing Stop (трейлинг-стоп) - защита прибыли
- Безубыток (перевод в безубыток при достижении определенной прибыли)

### ⏰ Временные фильтры
- Настройка времени торговли (начало и конец торговой сессии)
- Возможность торговли только в определенные часы
- Поддержка торговли через полночь

### 📈 Дополнительные функции
- Фильтр по максимальному спреду
- Статистика торговли
- Детальное логирование операций
- Сохранение и загрузка настроек

## Установка

### Шаг 1: Копирование файлов
1. Откройте MetaTrader 5
2. Выберите меню `Файл` → `Открыть каталог данных`
3. Перейдите в папку `MQL5\Experts`
4. Скопируйте файл `TradingRobot_MT5.mq5` в эту папку
5. Скопируйте файл `TradingRobotSettings.mqh` в папку `MQL5\Include`

### Шаг 2: Компиляция
1. В MetaTrader 5 откройте MetaEditor (F4)
2. Откройте файл `TradingRobot_MT5.mq5`
3. Нажмите кнопку `Компилировать` или F7
4. Убедитесь, что компиляция прошла без ошибок

### Шаг 3: Установка на график
1. В MetaTrader 5 откройте нужный график
2. В окне `Навигатор` найдите советник `TradingRobot_MT5`
3. Перетащите советник на график
4. В появившемся окне настройте параметры
5. Убедитесь, что автоторговля разрешена (кнопка `Авто-торговля` активна)

## Параметры робота

### Основные настройки
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| InpLotSize | Размер лота | 0.01 |
| InpMagicNumber | Уникальный идентификатор робота | 123456 |
| InpComment | Комментарий к сделкам | "MA Robot" |

### Параметры стратегии
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| InpFastMA | Период быстрой скользящей средней | 10 |
| InpSlowMA | Период медленной скользящей средней | 30 |
| InpMAMethod | Метод расчета MA (SMA/EMA/SMMA/LWMA) | MODE_SMA |
| InpMAPrice | Цена для расчета MA | PRICE_CLOSE |

### Управление рисками
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| InpStopLoss | Stop Loss в пунктах (0 = отключен) | 50 |
| InpTakeProfit | Take Profit в пунктах (0 = отключен) | 100 |
| InpTrailingStop | Trailing Stop в пунктах (0 = отключен) | 30 |
| InpMaxRiskPercent | Максимальный риск на сделку (%) | 2.0 |
| InpMaxPositions | Максимум открытых позиций | 1 |

### Временные настройки
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| InpUseTimeFilter | Использовать временной фильтр | false |
| InpStartHour | Час начала торговли | 9 |
| InpStartMinute | Минута начала торговли | 0 |
| InpEndHour | Час окончания торговли | 22 |
| InpEndMinute | Минута окончания торговли | 0 |

## Рекомендации по использованию

### Для начинающих
1. Начните с минимального лота (0.01)
2. Используйте демо-счет для тестирования
3. Установите Stop Loss не менее 30 пунктов
4. Ограничьте риск 1-2% от депозита
5. Используйте только одну открытую позицию

### Оптимальные настройки для разных рынков

#### Форекс (EUR/USD, GBP/USD)
- Быстрая MA: 8-12
- Медленная MA: 20-30
- Stop Loss: 30-50 пунктов
- Take Profit: 50-100 пунктов

#### Индексы (DAX, S&P500)
- Быстрая MA: 10-15
- Медленная MA: 30-50
- Stop Loss: 50-100 пунктов
- Take Profit: 100-200 пунктов

#### Криптовалюты
- Быстрая MA: 5-10
- Медленная MA: 20-30
- Stop Loss: 100-200 пунктов
- Take Profit: 200-500 пунктов

## Тестирование стратегии

### В тестере стратегий
1. Откройте `Тестер стратегий` (Ctrl+R)
2. Выберите советник `TradingRobot_MT5`
3. Выберите символ и таймфрейм
4. Установите период тестирования
5. Настройте параметры робота
6. Запустите тестирование

### Оптимизация параметров
1. В тестере включите режим `Оптимизация`
2. Отметьте параметры для оптимизации
3. Установите диапазоны значений
4. Выберите критерий оптимизации
5. Запустите оптимизацию

## Безопасность

### ⚠️ Важные предупреждения
- **Никогда не торгуйте деньгами, которые не можете позволить себе потерять**
- **Всегда тестируйте робота на демо-счете перед использованием на реальном счете**
- **Регулярно мониторьте работу робота**
- **Используйте VPS для бесперебойной работы**

### Рекомендации по безопасности
1. Всегда используйте Stop Loss
2. Не превышайте риск 2-3% на сделку
3. Диверсифицируйте торговлю (разные пары, таймфреймы)
4. Ведите журнал торговли
5. Регулярно выводите прибыль

## Устранение неполадок

### Робот не открывает сделки
- Проверьте, включена ли автоторговля
- Убедитесь, что есть связь с сервером
- Проверьте настройки времени торговли
- Проверьте достаточность средств на счете

### Ошибки при открытии позиций
- Проверьте размер минимального лота для символа
- Убедитесь в достаточности свободной маржи
- Проверьте правильность настроек SL/TP

### Робот закрывает сделки слишком рано
- Проверьте настройки Trailing Stop
- Убедитесь, что SL не слишком близко к цене открытия
- Проверьте волатильность рынка

## Поддержка и обновления

### Логирование
Робот автоматически ведет лог всех операций:
- Открытие/закрытие позиций
- Изменение SL/TP
- Ошибки и предупреждения

Логи можно найти во вкладке `Эксперты` терминала MT5.

### Файлы конфигурации
- `robot_settings.set` - сохраненные настройки робота
- `trading_statistics.csv` - статистика торговли
- `robot_log.txt` - детальный лог операций
