# 📱 Настройка для мобильных устройств

## Варианты использования на Android

### Вариант 1: Termux (Полноценный сервер на телефоне)

#### Установка

1. **Скачать Termux**
   - Источник: [F-Droid](https://f-droid.org/packages/com.termux/)
   - ⚠️ НЕ устанавливайте из Google Play (устаревшая версия)

2. **Первоначальная настройка Termux**
   ```bash
   # Обновить пакеты
   pkg update && pkg upgrade
   
   # Установить Python и необходимые инструменты
   pkg install python git wget
   
   # Установить pip
   pip install --upgrade pip
   ```

3. **Скачать проект**
   ```bash
   # Перейти в домашнюю директорию
   cd ~
   
   # Создать папку для проекта
   mkdir service-contracts
   cd service-contracts
   
   # Скопировать файлы проекта сюда
   # (можно через Share или wget с облака)
   ```

4. **Установить зависимости**
   ```bash
   pip install fastapi uvicorn python-multipart python-docx openpyxl pandas
   ```

5. **Запустить сервер**
   ```bash
   python backend.py
   ```

6. **Открыть в браузере**
   - На телефоне: `http://localhost:8000`
   - На другом устройстве в локальной сети: `http://[IP-адрес-телефона]:8000`

#### Узнать IP адрес в Termux
```bash
ifconfig wlan0 | grep inet
```

#### Автозапуск при старте Termux

Создать файл `~/.bashrc`:
```bash
echo "cd ~/service-contracts && python backend.py" >> ~/.bashrc
```

### Вариант 2: Подключение к серверу на компьютере

Если сервер запущен на компьютере Windows:

1. **На компьютере:**
   - Запустить `start_windows.bat`
   - Узнать IP адрес компьютера:
     ```cmd
     ipconfig
     ```
     Найти IPv4 адрес (например, 192.168.1.100)

2. **На Android:**
   - Открыть браузер Chrome
   - Перейти на `http://[IP-компьютера]:8000`
   - Добавить на главный экран для быстрого доступа

#### Создать ярлык приложения (PWA)

1. Открыть сайт в Chrome
2. Нажать меню (⋮)
3. Выбрать "Добавить на главный экран"
4. Подтвердить

Теперь система откроется как приложение!

### Вариант 3: UserLAnd (полноценный Linux на Android)

1. **Установить UserLAnd** из Google Play

2. **Создать Ubuntu окружение**

3. **Установить проект**
   ```bash
   sudo apt update
   sudo apt install python3 python3-pip
   pip3 install -r requirements.txt
   python3 backend.py
   ```

## iOS (iPhone/iPad)

### Через iSH (Linux оболочка для iOS)

1. **Установить iSH** из App Store

2. **Настроить**
   ```bash
   apk update
   apk add python3 py3-pip
   pip3 install fastapi uvicorn
   ```

3. **Запустить**
   ```bash
   python3 backend.py
   ```

### Через удаленный доступ

Подключиться к серверу на компьютере через браузер Safari:
- `http://[IP-адрес-компьютера]:8000`

## Синхронизация данных

### Между устройствами

**Вариант 1: Облачное хранилище**
```bash
# Копировать базу данных в облако
cp service_contracts.db ~/Dropbox/
```

**Вариант 2: Локальная синхронизация**
```bash
# На ПК
python -m http.server 8080

# На телефоне скачать БД
wget http://[IP-ПК]:8080/service_contracts.db
```

**Вариант 3: USB кабель**
- Подключить телефон к ПК
- Скопировать файл `service_contracts.db`

## Безопасность

### Доступ только в локальной сети

По умолчанию сервер доступен только в локальной сети.

### Для доступа из интернета (не рекомендуется)

Если все же нужно:

1. **Через VPN** (рекомендуется)
   - WireGuard
   - OpenVPN
   - Tailscale

2. **Через Ngrok** (для тестов)
   ```bash
   ngrok http 8000
   ```

⚠️ **Внимание**: Не рекомендуется открывать доступ из интернета без защиты!

## Troubleshooting

### Сервер не запускается

```bash
# Проверить занят ли порт
lsof -i :8000

# Использовать другой порт
python backend.py --port 8001
```

### Медленная работа

- Уменьшить количество данных
- Очистить кэш браузера
- Перезапустить сервер

### Ошибки при установке библиотек

```bash
# Обновить pip
pip install --upgrade pip

# Установить по одной
pip install fastapi
pip install uvicorn
```
