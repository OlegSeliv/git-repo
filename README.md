# Система управления сервисными контрактами

Комплексная система для управления сервисными контрактами, заказами, материалами, командировками и документооборотом.

## Возможности системы

### 🎯 Основной функционал
- **Управление контрактами**: создание, редактирование, мониторинг статуса
- **Управление заказами**: планирование, выполнение, контроль сроков
- **Склад материалов**: учет, контроль дефицита, планирование закупок
- **Командировки**: планирование, оформление документов, продление
- **Документооборот**: автоматическое создание актов, удостоверений, служебок
- **Финансовый контроль**: мониторинг балансов, платежей, расчетов
- **Аналитика и отчеты**: детальные отчеты и графики

### 📱 Платформы
- **Веб-интерфейс**: полнофункциональная система на Flask
- **Android приложение**: мобильное управление для полевых работ  
- **Windows приложение**: нативное приложение для рабочих мест

### 📄 Документооборот
- Автоматическое создание актов выполненных работ
- Генерация удостоверений военного представителя
- Формирование актов сдачи-приемки
- Создание служебных заданий на командировки
- Сканирование и OCR распознавание документов
- Система хранения с поиском и версионностью

## Требования к системе

### Программное обеспечение
- **Python**: версия 3.8 или выше
- **Операционная система**: Windows 10+, Linux, macOS
- **Браузер**: Chrome, Firefox, Safari (последние версии)
- **Tesseract OCR**: для распознавания сканированных документов

### Аппаратные требования
- **ОЗУ**: минимум 4 ГБ, рекомендуется 8 ГБ
- **Процессор**: двухядерный 2 ГГц или выше
- **Диск**: минимум 2 ГБ свободного места
- **Сеть**: для работы веб-интерфейса

## Установка и настройка

### Автоматическая установка

1. **Скачайте проект**:
```bash
git clone <repository-url>
cd contract-management-system
```

2. **Запустите установщик**:
```bash
python setup.py
```

Установщик автоматически:
- Проверит версию Python
- Установит необходимые библиотеки
- Создаст структуру папок
- Инициализирует базу данных с тестовыми данными
- Создаст конфигурационные файлы
- Настроит скрипты запуска

### Ручная установка

1. **Установите зависимости**:
```bash
pip install -r requirements.txt
```

2. **Инициализируйте базу данных**:
```bash
python -c "
from app import app, init_db
with app.app_context():
    init_db()
"
```

3. **Создайте необходимые папки**:
```bash
mkdir -p {documents,scans,uploads,templates,reports,backups,logs}
```

### Установка Tesseract OCR

**Windows:**
1. Скачайте с https://github.com/UB-Mannheim/tesseract/wiki
2. Установите в стандартную папку
3. Добавьте путь в PATH или укажите в коде

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install tesseract-ocr tesseract-ocr-rus
```

**macOS:**
```bash
brew install tesseract tesseract-lang
```

## Использование системы

### Основные бизнес-процессы

1. **Создание контракта**:
   - Добавьте новый контракт через веб-интерфейс
   - Укажите заказчика, сумму, сроки
   - Создайте субсчет для финансового учета

2. **Планирование заказа**:
   - Создайте заказ в рамках контракта
   - Укажите требуемые материалы
   - Спланируйте командировки при необходимости

3. **Управление материалами**:
   - Ведите учет складских остатков
   - Контролируйте дефицит
   - Оформляйте заказы поставщикам

4. **Выполнение работ**:
   - Отслеживайте прогресс заказов
   - Создавайте акты выполненных работ
   - Получайте удостоверения военпреда
   - Формируйте акты сдачи-приемки

5. **Финансовый контроль**:
   - Мониторьте балансы контрактов
   - Отслеживайте поступления платежей
   - Требуйте доплаты при необходимости

1. **Сканирование**:
   - Используйте встроенную систему сканирования

2. **Автогенерация**:
   - Акты работ создаются автоматически
   - Заполнение на основе данных системы
   - Возможность редактирования перед сохранением

3. **Хранение**:
   - Структурированное хранение по типам
   - Версионность документов
   - Связи между документами

## API

Система предоставляет REST API для интеграции:

### Контракты
```http
GET /api/contracts          # Список контрактов
POST /api/contracts         # Создание контракта
GET /api/contracts/{id}     # Данные контракта
PUT /api/contracts/{id}     # Обновление контракта
DELETE /api/contracts/{id}  # Удаление контракта
```

### Заказы
```http
GET /api/orders            # Список заказов
POST /api/orders           # Создание заказа
GET /api/orders/{id}       # Данные заказа
PUT /api/orders/{id}/start # Начать выполнение
```

### Документы
```http
POST /api/documents/upload    # Загрузка файла
GET /api/documents/search     # Поиск документов
GET /api/documents/{id}       # Метаданные документа
GET /api/documents/{id}/download # Скачивание файла
```

### Аналитика
```http
GET /api/dashboard_stats    # Статистика дашборда
GET /api/analytics/contracts # Аналитика контрактов
GET /api/analytics/financial # Финансовая аналитика
```

## Устранение неполадок

### Частые проблемы

1. **Не запускается веб-сервер**:
   - Проверьте, свободен ли порт 5000
   - Убедитесь, что все зависимости установлены
   - Проверьте права доступа к папкам

2. **Не работает OCR**:
   - Установите Tesseract OCR
   - Проверьте путь к tesseract.exe в коде
   - Установите русские языковые пакеты

3. **Ошибки базы данных**:
   - Проверьте права доступа к файлу БД
   - Убедитесь, что схема актуальна
   - При необходимости пересоздайте БД

4. **Проблемы с документами**:
   - Проверьте права доступа к папкам
   - Убедитесь в наличии свободного места
   - Проверьте размер загружаемых файлов

### Логи

Логи системы сохраняются в папке `logs/`:
- `app.log` - основные события приложения
- `error.log` - ошибки системы
- `access.log` - журнал доступа

## Разработка и расширение

### Архитектура
- **Backend**: Flask + SQLAlchemy
- **Frontend**: HTML5 + Bootstrap + JavaScript
- **Mobile**: Kivy (Python)
- **Desktop**: Tkinter (Python)
- **Database**: SQLite (можно заменить на PostgreSQL/MySQL)

### Добавление функций

1. **Новая модель данных**:
   - Добавьте класс в `app.py`
   - Создайте миграцию БД
   - Обновите API методы

2. **Новый тип документа**:
   - Добавьте шаблон в `document_generator.py`
   - Обновите маршруты создания документов
   - Добавьте в систему хранения

3. **Новый отчет**:
   - Создайте метод в `analytics_reporting.py`
   - Добавьте маршрут в API
   - Обновите интерфейс
