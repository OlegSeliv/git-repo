# RSI + StochRSI Trading Bot для TradingView

## Описание

Торговый робот для TradingView, использующий комбинацию индикаторов RSI и StochRSI на разных таймфреймах для генерации торговых сигналов.

## Файлы проекта

1. **trading_bot_rsi_stochrsi.pine** - Основная стратегия (Strategy) для автоматической торговли
2. **rsi_stochrsi_indicator.pine** - Индикатор для визуального анализа сигналов

## Логика работы

### Сигналы для ЛОНГ позиций

**Условия входа:**
- RSI на 4-часовом таймфрейме > 50 (бычий тренд)
- StochRSI на 15-минутном таймфрейме пересекает уровень 25 снизу вверх
- При наличии бычьей дивергенции вероятность входа увеличивается

**Условия выхода:**
- StochRSI на 15-минутном таймфрейме пересекает уровень 80 сверху вниз

### Сигналы для ШОРТ позиций

**Условия входа:**
- RSI на 4-часовом таймфрейме < 50 (медвежий тренд)
- StochRSI на 15-минутном таймфрейме пересекает уровень 75 сверху вниз
- При наличии медвежьей дивергенции вероятность входа увеличивается

**Условия выхода:**
- StochRSI на 15-минутном таймфрейме пересекает уровень 20 снизу вверх

## Установка в TradingView

### Установка стратегии (trading_bot_rsi_stochrsi.pine)

1. Откройте TradingView
2. Откройте Pine Editor (внизу графика)
3. Нажмите "Открыть" → "Новая пустая стратегия"
4. Скопируйте код из файла `trading_bot_rsi_stochrsi.pine`
5. Вставьте код в редактор
6. Нажмите "Сохранить" и дайте стратегии имя
7. Нажмите "Добавить на график"

### Установка индикатора (rsi_stochrsi_indicator.pine)

1. В Pine Editor нажмите "Открыть" → "Новый пустой индикатор"
2. Скопируйте код из файла `rsi_stochrsi_indicator.pine`
3. Вставьте код в редактор
4. Сохраните и добавьте на график

## Настраиваемые параметры

### RSI настройки
- **RSI Length (4H)** - период RSI для 4-часового таймфрейма (по умолчанию: 14)
- **RSI Trend Level** - уровень для определения тренда (по умолчанию: 50)

### StochRSI настройки
- **RSI Length** - период RSI для расчета StochRSI (по умолчанию: 8)
- **Stoch Length** - период стохастика (по умолчанию: 5)
- **Smooth K** - сглаживание линии K (по умолчанию: 3)
- **Smooth D** - сглаживание линии D (по умолчанию: 3)

### Уровни StochRSI
- **Long Entry Level** - уровень входа в лонг (по умолчанию: 25)
- **Long Exit Level** - уровень выхода из лонга (по умолчанию: 80)
- **Short Entry Level** - уровень входа в шорт (по умолчанию: 75)
- **Short Exit Level** - уровень выхода из шорта (по умолчанию: 20)

### Дивергенции
- **Use RSI Divergence** - использовать дивергенции для усиления сигналов
- **Divergence Lookback Bars** - количество баров для поиска дивергенций
- **Min Bars Between Pivots** - минимальное расстояние между пиками/впадинами

## Особенности

1. **Мультитаймфреймовый анализ** - использует RSI на 4H для определения общего тренда и StochRSI на 15M для точных точек входа

2. **Дивергенции** - автоматически определяет бычьи и медвежьи дивергенции RSI для повышения точности сигналов

3. **Информационная панель** - отображает текущие значения индикаторов и статус позиции

4. **Визуализация** - четкие маркеры входа/выхода на графике

5. **Алерты** - настраиваемые оповещения для всех типов сигналов

## Рекомендации по использованию

1. **Тестирование** - обязательно протестируйте стратегию на исторических данных перед реальной торговлей

2. **Таймфрейм графика** - рекомендуется использовать на 15-минутном графике для лучшей визуализации сигналов

3. **Риск-менеджмент** - добавьте собственные правила управления капиталом и стоп-лоссы

4. **Оптимизация** - настройте параметры под конкретный инструмент и рыночные условия

5. **Дополнительные фильтры** - рассмотрите добавление дополнительных индикаторов или фильтров для повышения точности

## Предупреждение о рисках

Данная стратегия предоставляется исключительно в образовательных целях. Торговля на финансовых рынках сопряжена с высоким риском потери капитала. Всегда проводите собственный анализ и тестирование перед использованием любой торговой стратегии с реальными средствами.
