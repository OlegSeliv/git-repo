# Торговый Робот для MT5

Автоматизированный торговый робот (Expert Advisor) для платформы MetaTrader 5, использующий стратегию пересечения скользящих средних (Moving Average Crossover).

## 📋 Описание

Этот торговый робот открывает позиции на основе пересечения двух скользящих средних:
- **Сигнал на покупку (BUY)**: Быстрая MA пересекает медленную MA снизу вверх
- **Сигнал на продажу (SELL)**: Быстрая MA пересекает медленную MA сверху вниз

## ✨ Функциональность

### Основные возможности:
- ✅ Стратегия на основе пересечения Moving Average
- ✅ Гибкая настройка параметров индикаторов
- ✅ Управление рисками с фиксированным или автоматическим расчетом лота
- ✅ Установка Stop Loss и Take Profit
- ✅ Трейлинг-стоп для фиксации прибыли
- ✅ Защита от одновременного открытия нескольких позиций
- ✅ Подробное логирование всех операций

## 🚀 Установка

### 1. Копирование файлов
Скопируйте файл `TradingRobot.mq5` в папку:
```
C:\Users\[Ваше_имя]\AppData\Roaming\MetaQuotes\Terminal\[ID_терминала]\MQL5\Experts\
```

### 2. Компиляция
1. Откройте MetaTrader 5
2. Нажмите `F4` или откройте MetaEditor
3. Найдите файл `TradingRobot.mq5` в навигаторе
4. Нажмите `F7` или кнопку "Compile"
5. Убедитесь, что компиляция прошла без ошибок

### 3. Установка на график
1. Откройте нужный торговый инструмент (например, EURUSD)
2. Выберите таймфрейм (рекомендуется H1 или H4)
3. В навигаторе найдите "TradingRobot" в разделе "Expert Advisors"
4. Перетащите робота на график
5. Настройте параметры в открывшемся окне
6. Убедитесь, что включена кнопка "AutoTrading" (в верхней панели MT5)

## ⚙️ Параметры робота

### Параметры стратегии
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `FastMA_Period` | Период быстрой скользящей средней | 10 |
| `SlowMA_Period` | Период медленной скользящей средней | 30 |
| `MA_Method` | Метод расчета MA (SMA, EMA, SMMA, LWMA) | SMA |
| `MA_Price` | Применяемая цена (Close, Open, High, Low) | CLOSE |

### Управление рисками
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `LotSize` | Фиксированный размер лота | 0.1 |
| `UseAutoLot` | Использовать автоматический расчет лота | false |
| `RiskPercent` | Процент риска от баланса (при UseAutoLot=true) | 2.0% |
| `StopLoss` | Стоп-лосс в пунктах | 100 |
| `TakeProfit` | Тейк-профит в пунктах | 200 |

### Дополнительные настройки
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `MagicNumber` | Уникальный идентификатор робота | 123456 |
| `TradeComment` | Комментарий к сделкам | "MA Robot" |
| `Slippage` | Максимальное проскальзывание | 10 |
| `UseTrailingStop` | Использовать трейлинг-стоп | false |
| `TrailingStop` | Дистанция трейлинга в пунктах | 50 |
| `TrailingStep` | Минимальный шаг трейлинга | 10 |

## 📊 Рекомендуемые настройки

### Для начинающих (консервативная торговля)
```
FastMA_Period = 10
SlowMA_Period = 30
LotSize = 0.01
UseAutoLot = false
StopLoss = 100
TakeProfit = 200
UseTrailingStop = false
```

### Для опытных трейдеров (агрессивная торговля)
```
FastMA_Period = 5
SlowMA_Period = 20
UseAutoLot = true
RiskPercent = 2.0
StopLoss = 50
TakeProfit = 150
UseTrailingStop = true
TrailingStop = 30
TrailingStep = 10
```

### Для разных таймфреймов
- **M15-M30**: FastMA=5, SlowMA=15, SL=50, TP=100
- **H1**: FastMA=10, SlowMA=30, SL=100, TP=200
- **H4**: FastMA=20, SlowMA=50, SL=200, TP=400
- **D1**: FastMA=30, SlowMA=100, SL=500, TP=1000

## 🧪 Тестирование

### Тестирование в Strategy Tester
1. Откройте Strategy Tester (`Ctrl+R`)
2. Выберите "TradingRobot" в списке экспертов
3. Выберите торговый инструмент
4. Выберите период тестирования
5. Настройте параметры робота
6. Нажмите "Start" для начала тестирования

### Рекомендации по тестированию
- Тестируйте на исторических данных минимум за 1 год
- Используйте режим "Every tick" для точности
- Проверьте результаты на разных валютных парах
- Оптимизируйте параметры для конкретного инструмента

## ⚠️ Важные замечания

### Риски
- ⚠️ **Торговля на финансовых рынках сопряжена с высоким риском**
- ⚠️ Всегда тестируйте робота на демо-счете перед реальной торговлей
- ⚠️ Не рискуйте деньгами, которые не можете позволить себе потерять
- ⚠️ Прошлые результаты не гарантируют будущей прибыли

### Рекомендации
- ✅ Используйте автоматический расчет лота с риском не более 1-2% на сделку
- ✅ Всегда устанавливайте Stop Loss
- ✅ Регулярно проверяйте работу робота
- ✅ Тестируйте новые настройки на демо-счете
- ✅ Не запускайте несколько роботов с одинаковым MagicNumber

### Проблемы и решения

**Робот не открывает позиции:**
- Проверьте, включена ли кнопка "AutoTrading"
- Убедитесь, что нет ошибок в логе (вкладка "Experts")
- Проверьте настройки брокера (минимальный лот, доступные инструменты)

**Ошибки при открытии ордеров:**
- Проверьте доступный баланс
- Убедитесь, что размер лота соответствует требованиям брокера
- Проверьте правильность значений Stop Loss и Take Profit

**Робот открывает слишком много позиций:**
- Убедитесь, что функция `IsPositionOpen()` работает корректно
- Проверьте уникальность MagicNumber

## 📈 Оптимизация стратегии

Для улучшения результатов вы можете:

1. **Оптимизация периодов MA:**
   - Используйте Strategy Tester для поиска оптимальных периодов
   - Тестируйте разные комбинации (5/15, 10/30, 20/50)

2. **Добавление фильтров:**
   - Добавьте фильтр по тренду (например, по более старшему таймфрейму)
   - Используйте дополнительные индикаторы (RSI, MACD, ATR)

3. **Управление рисками:**
   - Настройте соотношение Risk/Reward минимум 1:2
   - Используйте трейлинг-стоп для фиксации прибыли

4. **Выбор инструментов:**
   - Тестируйте на разных валютных парах
   - Выбирайте инструменты с низким спредом
