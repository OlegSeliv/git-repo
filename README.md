# Торговый Робот для MetaTrader 5

Автоматический торговый робот (Expert Advisor) для платформы MetaTrader 5, использующий стратегию пересечения скользящих средних.

## Описание стратегии

Робот использует классическую стратегию пересечения двух скользящих средних:
- **Сигнал на покупку**: Быстрая MA пересекает медленную MA снизу вверх
- **Сигнал на продажу**: Быстрая MA пересекает медленную MA сверху вниз

## Основные возможности

### ✅ Торговая логика
- Автоматическое определение сигналов входа
- Настраиваемые периоды скользящих средних
- Выбор метода расчета MA (SMA, EMA, SMMA, LWMA)

### ✅ Управление рисками
- Автоматический расчет размера лота на основе риска
- Настраиваемые стоп-лосс и тейк-профит
- Ограничение максимального количества позиций
- Контроль максимального риска в процентах от депозита

### ✅ Временные фильтры
- Настройка времени торговли (часы начала и окончания)
- Возможность отключения торговли в пятницу
- Защита от торговли в нерабочее время

### ✅ Дополнительные функции
- Магический номер для идентификации сделок
- Настраиваемый комментарий к сделкам
- Подробное логирование операций

## Установка и настройка

### 1. Установка в MetaTrader 5

1. Скопируйте файл `TradingRobot.mq5` в папку:
   ```
   MetaTrader 5/MQL5/Experts/
   ```

2. Откройте MetaEditor и скомпилируйте файл (F7)

3. В терминале MT5 перейдите в Navigator → Expert Advisors

4. Перетащите робота на график нужного инструмента

### 2. Настройка параметров

#### Основные настройки
- **LotSize** (0.1) - Базовый размер лота
- **MagicNumber** (12345) - Уникальный номер для идентификации сделок
- **TradeComment** - Комментарий к сделкам

#### Параметры стратегии
- **FastMA_Period** (10) - Период быстрой скользящей средней
- **SlowMA_Period** (20) - Период медленной скользящей средней
- **MA_Method** (EMA) - Метод расчета MA
- **MA_Price** (CLOSE) - Цена для расчета MA

#### Управление рисками
- **StopLoss** (50) - Стоп-лосс в пунктах
- **TakeProfit** (100) - Тейк-профит в пунктах
- **MaxRiskPercent** (2.0) - Максимальный риск в % от депозита
- **MaxOpenPositions** (1) - Максимальное количество позиций

#### Временные фильтры
- **StartHour** (9) - Час начала торговли
- **EndHour** (17) - Час окончания торговли
- **TradeOnFriday** (true) - Торговать в пятницу

## Рекомендации по использованию

### Выбор инструментов
- Лучше всего работает на валютных парах с хорошей ликвидностью
- Рекомендуемые таймфреймы: H1, H4, D1
- Избегайте экзотических пар с большими спредами

### Настройка параметров
- Для волатильных инструментов увеличьте стоп-лосс и тейк-профит
- На младших таймфреймах используйте меньшие периоды MA
- Не устанавливайте риск более 5% от депозита

### Мониторинг
- Регулярно проверяйте журнал операций
- Следите за просадкой и прибыльностью
- Корректируйте параметры на основе результатов

## Предупреждения

⚠️ **ВАЖНО**: Торговля на финансовых рынках связана с высоким риском потери средств. Данный робот предназначен только для образовательных целей.

⚠️ **Тестирование**: Обязательно протестируйте робота на демо-счете перед использованием на реальном счете.

⚠️ **Оптимизация**: Проведите оптимизацию параметров на исторических данных для выбранного инструмента.
