# Система управления сервисными контрактами

Комплексная система для управления сервисными контрактами, включающая веб-интерфейс для Windows и мобильное приложение для Android.

## Основные возможности

### 🏢 Управление контрактами
- Создание и редактирование сервисных контрактов
- Отслеживание статусов и сроков выполнения
- Финансовый контроль (авансы, доплаты, расходы)
- Автоматическое формирование документов

### 📋 Управление заказами
- Планирование и контроль выполнения заказов
- Приоритизация задач
- Привязка к контрактам и материалам
- Отслеживание местоположения работ

### 📦 Управление материалами
- Учет материалов и комплектующих
- Контроль складских остатков
- Резервирование материалов под заказы
- Отслеживание дефицита и поставщиков

### ✈️ Управление командировками
- Планирование командировок сотрудников
- Контроль расходов и сроков
- Интеграция с заказами и контрактами
- Автоматические напоминания

### 📄 Документооборот
- Автоматическое формирование документов
- Сканирование и архивирование
- Шаблоны контрактов, актов, протоколов
- Поиск по физическому и электронному архиву

### 📊 Отчетность и аналитика
- Финансовые отчеты
- Отчеты по материалам и дефициту
- Аналитика выполнения контрактов
- Экспорт в Excel

### 🔔 Система уведомлений
- Автоматические напоминания
- Email уведомления
- Контроль дефицита материалов
- Мониторинг сроков

## Установка и настройка

### Требования к системе

**Сервер:**
- Node.js 16+ 
- PostgreSQL 12+
- 4GB RAM (минимум)
- 50GB свободного места

**Клиент (Windows):**
- Windows 10/11
- Современный браузер (Chrome, Firefox, Edge)
- 2GB RAM

**Мобильное приложение:**
- Android 7.0+ (API 24+)
- 100MB свободного места

### Установка сервера

1. **Клонирование репозитория:**
```bash
git clone <repository-url>
cd service-contracts-management
```

2. **Установка зависимостей:**
```bash
npm install
```

3. **Настройка базы данных:**
```bash
# Создание базы данных
createdb service_contracts_db

# Запуск SQL скрипта
psql -d service_contracts_db -f database_schema.sql
```

4. **Настройка переменных окружения:**
```bash
cp .env.example .env
# Отредактируйте .env файл с вашими настройками
```

5. **Запуск сервера:**
```bash
npm start
```

### Установка веб-интерфейса

Веб-интерфейс автоматически доступен после запуска сервера по адресу:
```
http://localhost:3000
```

### Установка Android приложения

1. **Откройте проект в Android Studio:**
```
File -> Open -> выберите папку android/
```

2. **Настройте подключение к серверу:**
Отредактируйте файл `android/app/src/main/java/ru/servicecontracts/mobile/data/api/ApiClient.kt`:
```kotlin
private const val BASE_URL = "http://YOUR_SERVER_IP:3000/api/"
```

3. **Соберите и установите приложение:**
```bash
cd android
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Конфигурация

### Настройка базы данных

Создайте файл `.env` в корневой папке:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=service_contracts_db
DB_USER=postgres
DB_PASSWORD=your_password
JWT_SECRET=your_jwt_secret
```

### Настройка email уведомлений

Добавьте в `.env`:
```env
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_app_password
EMAIL_FROM=your_email@gmail.com
EMAIL_TO=admin@company.com
```

### Настройка хранения документов

Создайте папки для хранения:
```bash
mkdir -p uploads/documents
mkdir -p uploads/scans
mkdir -p generated_documents
mkdir -p reports
```

## Использование

### Первый запуск

1. Откройте веб-интерфейс в браузере
2. Войдите с учетными данными по умолчанию:
   - Логин: `admin`
   - Пароль: `admin`
3. Смените пароль в настройках

### Основные операции

#### Создание контракта
1. Перейдите в раздел "Контракты"
2. Нажмите "Добавить контракт"
3. Заполните все необходимые поля
4. Сохраните контракт

#### Создание заказа
1. Перейдите в раздел "Заказы"
2. Нажмите "Добавить заказ"
3. Выберите контракт
4. Заполните описание и местоположение
5. Сохраните заказ

#### Управление материалами
1. Перейдите в раздел "Материалы"
2. Добавьте материалы через "Добавить материал"
3. Укажите количество на складе
4. Резервируйте материалы под заказы

#### Планирование командировок
1. Перейдите в раздел "Командировки"
2. Нажмите "Добавить командировку"
3. Выберите сотрудника и заказ
4. Укажите направление и сроки

#### Работа с документами
1. Перейдите в раздел "Документы"
2. Загрузите документы через "Загрузить документ"
3. Укажите физическое место хранения
4. Используйте поиск для быстрого доступа

### Мобильное приложение

#### Основные функции
- Просмотр контрактов и заказов
- Сканирование документов
- Создание заказов в полевых условиях
- Получение уведомлений

#### Синхронизация
- Автоматическая синхронизация при подключении к интернету
- Офлайн режим с последующей синхронизацией
- Конфликт-резолюшн при синхронизации

## API Документация

### Аутентификация
```http
POST /api/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "admin"
}
```

### Основные эндпоинты

#### Контракты
- `GET /api/contracts` - Список контрактов
- `POST /api/contracts` - Создание контракта
- `PUT /api/contracts/:id` - Обновление контракта
- `DELETE /api/contracts/:id` - Удаление контракта

#### Заказы
- `GET /api/orders` - Список заказов
- `POST /api/orders` - Создание заказа
- `PUT /api/orders/:id` - Обновление заказа

#### Материалы
- `GET /api/materials` - Список материалов
- `POST /api/materials` - Добавление материала
- `GET /api/analytics/materials-deficit` - Дефицит материалов

#### Документы
- `GET /api/documents` - Список документов
- `POST /api/documents/upload` - Загрузка документа
- `GET /api/documents/:id/download` - Скачивание документа

## Устранение неполадок

### Частые проблемы

#### Ошибка подключения к базе данных
- Проверьте настройки в `.env`
- Убедитесь, что PostgreSQL запущен
- Проверьте права доступа пользователя

#### Ошибки загрузки файлов
- Проверьте права на папку `uploads/`
- Убедитесь в наличии свободного места
- Проверьте настройки `multer`

#### Проблемы с мобильным приложением
- Проверьте подключение к серверу
- Убедитесь в правильности URL в настройках
- Проверьте сертификаты SSL

Включите подробное логирование:
