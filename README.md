# TrendFollowingBot - Торговый робот для MT5

## Описание

TrendFollowingBot - это Expert Advisor для MetaTrader 5, который использует комбинацию индикаторов RSI и Stochastic для определения точек входа и выхода из сделок.

## Логика работы

### Определение направления тренда
- **RSI на H4 > 50** - поиск сигналов для покупки (лонг)
- **RSI на H4 < 50** - поиск сигналов для продажи (шорт)

### Сигналы входа

#### Для покупки (лонг):
- RSI на H4 должен быть выше 50
- Stochastic на M15 должен подниматься снизу вверх и закрепляться выше уровня 25
- Условие: предыдущие 2 значения стохастика < 25, текущее > 25 и растет

#### Для продажи (шорт):
- RSI на H4 должен быть ниже 50  
- Stochastic на M15 должен опускаться сверху вниз и закрепляться ниже уровня 75
- Условие: предыдущие 2 значения стохастика > 75, текущее < 75 и падает

### Управление рисками

#### Стоп-лосс:
- Рассчитывается как 2 * ATR на таймфрейме M15
- Устанавливается автоматически при открытии позиции

#### Выход из сделки:
- **Лонг**: закрытие при достижении Stochastic уровня 95
- **Шорт**: закрытие при достижении Stochastic уровня 5

## Входные параметры

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| LotSize | 0.1 | Размер лота для торговли |
| RSI_Period | 14 | Период индикатора RSI |
| Stoch_K_Period | 5 | Период %K стохастика |
| Stoch_D_Period | 3 | Период %D стохастика |
| Stoch_Slowing | 3 | Замедление стохастика |
| ATR_Period | 14 | Период индикатора ATR |
| ATR_Multiplier | 2.0 | Множитель ATR для расчета стоп-лосса |
| MagicNumber | 123456 | Уникальный номер для идентификации ордеров |

## Установка и использование

1. **Установка:**
   - Скопируйте файл `TrendFollowingBot.mq5` в папку `MQL5/Experts/` вашего терминала MT5
   - Перекомпилируйте советник в MetaEditor

2. **Настройка:**
   - Откройте график нужного инструмента
   - Перетащите советник на график или используйте меню "Вставка" → "Советники"
   - Настройте входные параметры по необходимости
   - Убедитесь, что включена автоторговля

3. **Мониторинг:**
   - Следите за журналом для отслеживания сигналов и сделок
   - Робот автоматически управляет позициями согласно заложенной логике

## Особенности работы

- Робот работает только с одной позицией одновременно
- Новые сигналы игнорируются при наличии открытой позиции
- Автоматическое управление стоп-лоссом на основе ATR
- Автоматическое закрытие по условиям стохастика

## Рекомендации

1. **Тестирование:** Обязательно протестируйте робота на демо-счете или в тестере стратегий
2. **Таймфреймы:** Убедитесь, что у вас есть данные для H4 и M15 таймфреймов
3. **Риск-менеджмент:** Настройте размер лота в соответствии с вашим депозитом
4. **Мониторинг:** Регулярно проверяйте работу робота и корректируйте параметры при необходимости

## Предупреждения

- Торговля на финансовых рынках связана с высоким риском
- Прошлые результаты не гарантируют будущую прибыльность
- Всегда тестируйте стратегию перед использованием на реальном счете
- Используйте только тот капитал, потерю которого вы можете себе позволить
