# Торговый робот для MetaTrader 5

## Описание стратегии

Этот торговый робот (Expert Advisor) реализует стратегию, основанную на комбинации индикаторов RSI, Stochastic и ATR.

### Логика работы:

1. **Определение тренда (H4)**:
   - RSI > 50 → Восходящий тренд (ищем вход в LONG)
   - RSI < 50 → Нисходящий тренд (ищем вход в SHORT)

2. **Условия входа (M15)**:
   - **Для LONG**: Стохастик поднимается снизу вверх и закрепляется выше уровня 25
   - **Для SHORT**: Стохастик опускается сверху вниз и закрепляется ниже уровня 75

3. **Расчет Stop Loss**:
   - Stop Loss = 2 × ATR (M15)

4. **Условия выхода (M15)**:
   - **Для LONG**: Стохастик достигает уровня 95
   - **Для SHORT**: Стохастик достигает уровня 5

## Установка

1. Скопируйте файл `TradingRobot.mq5` в папку:
   ```
   MetaTrader 5/MQL5/Experts/
   ```

2. В MetaTrader 5 откройте MetaEditor (F4) и найдите файл TradingRobot.mq5

3. Нажмите "Compile" (F7) для компиляции советника

4. После успешной компиляции советник появится в окне "Navigator" в разделе "Expert Advisors"

## Использование

1. Перетащите советник на график валютной пары

2. В окне настроек можно изменить параметры:
   - **LotSize** (0.1): Размер лота по умолчанию
   - **RSI_Period** (14): Период индикатора RSI
   - **Stochastic_K** (5): Период %K стохастика
   - **Stochastic_D** (3): Период %D стохастика
   - **Stochastic_Slowing** (3): Замедление стохастика
   - **ATR_Period** (14): Период ATR
   - **ATR_Multiplier** (2.0): Множитель ATR для расчета Stop Loss
   - **Magic** (123456): Уникальный идентификатор советника

3. Убедитесь, что в настройках включен параметр "Allow Algo Trading"

4. Нажмите OK для активации робота

## Важные замечания

- ⚠️ **Используйте на реальном счете на свой риск!** Рекомендуется сначала протестировать на демо-счете
- Робот работает только с одной позицией одновременно
- Убедитесь, что у вас достаточно свободной маржи для открытия позиций
- Рекомендуется использовать VPS для непрерывной работы робота
- Робот не использует Take Profit, только Stop Loss и сигнал выхода по Stochastic

## Логирование

Робот выводит информацию о своих действиях в журнал (вкладка "Experts"):
- Открытие и закрытие позиций
- Значения индикаторов
- Ошибки при выполнении торговых операций

## Рекомендации по использованию

1. **Выбор валютной пары**: Лучше всего работает на ликвидных парах (EUR/USD, GBP/USD, USD/JPY)
2. **Тестирование**: Проведите бэктест на исторических данных минимум за 6-12 месяцев
3. **Управление рисками**: Не рискуйте более 1-2% капитала на одну сделку
4. **Мониторинг**: Регулярно проверяйте работу робота и результаты

## Структура кода

- `OnInit()`: Инициализация индикаторов
- `OnTick()`: Основная логика, вызывается на каждом тике
- `CheckEntryConditions()`: Проверка условий входа в позицию
- `CheckExitConditions()`: Проверка условий выхода из позиции
- `OpenLongPosition()`: Открытие длинной позиции с расчетом SL
- `OpenShortPosition()`: Открытие короткой позиции с расчетом SL

## Техническая поддержка

При возникновении ошибок проверьте:
1. Корректность компиляции советника
2. Наличие разрешения на автоматическую торговлю
3. Достаточность свободной маржи
4. Правильность настроек брокера (некоторые брокеры требуют минимальное расстояние для Stop Loss)
