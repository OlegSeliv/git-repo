# Система управления сервисными контрактами

Комплексная система для управления сервисными контрактами, заказами, материалами, командировками и документооборотом.

## 📋 Основные возможности

### 1. Управление контрактами
- Ведение нескольких сервисных контрактов одновременно
- Отслеживание сроков действия контрактов
- Контроль бюджета и субсчетов
- Управление финансированием (авансирование и окончательный расчет)
- Автоматические уведомления о дефиците средств

### 2. Управление заказами на выполнение работ
- Регистрация поступающих заказов
- Отслеживание местоположения устройств (на заводе/в регионах)
- Контроль сроков выполнения работ
- Приоритизация заказов
- Учет плановой и фактической стоимости

### 3. Управление материалами и комплектующими
- Учет материалов на складе
- Контроль дефицита комплектующих с предупреждениями
- Автоматические заявки на основе актов дефектации
- Отслеживание заказов у поставщиков
- Учет использования материалов в разных контрактах

### 4. Управление командировками
- Планирование командировок сотрудников
- Контроль продлений через HR
- Карта текущих командировок по регионам
- Проверка наличия средств перед командировкой
- График командировок с напоминаниями

### 5. Финансовый учет
- Двухэтапная оплата (авансирование + окончательный расчет)
- Контроль баланса субсчетов
- Проверка наличия денег перед выполнением заказов
- Аналитика оплат vs выполненных работ
- Автоматическая генерация писем о доплате

### 6. Документооборот
- Хранение всех документов в единой базе
- Автоматическое заполнение документов по шаблонам:
  - Акты окончательной технической приемки
  - Удостоверения военпреда
  - Акты сдачи-приемки выполненных работ
  - Письма заказчикам
- Сканирование и хранение подписанных документов
- Привязка электронных и бумажных копий
- Указание места хранения бумажных оригиналов

### 7. Протоколы совещаний
- Ведение протоколов совещаний с заказчиками и поставщиками
- Контроль выполнения задач из протоколов
- Отслеживание сроков выполнения
- История переписки

### 8. Аналитика и отчеты
- Дашборд с ключевыми показателями
- Отчеты по контрактам, заказам, платежам
- Анализ дефицита материалов
- Excel-таблицы для бухгалтерии
- Визуализация хода выполнения контрактов

## 🚀 Установка и запуск

### Для Windows

1. **Установить Python 3.8 или выше**
   - Скачать с [python.org](https://python.org)
   - При установке отметить "Add Python to PATH"

2. **Установить зависимости**
   ```cmd
   python -m pip install -r requirements.txt
   ```

3. **Запустить систему**
   
   Двойной клик на файл `start_windows.bat` или выполнить в командной строке:
   ```cmd
   start_windows.bat
   ```

4. **Открыть в браузере**
   - Автоматически откроется `http://localhost:8000`
   - Или открыть файл `frontend.html` в браузере

### Для Android

**Вариант 1: Через локальный сервер**
1. Установить Termux из F-Droid
2. В Termux выполнить:
   ```bash
   pkg install python
   pip install -r requirements.txt
   python backend.py
   ```
3. Открыть в браузере `http://localhost:8000`

**Вариант 2: Progressive Web App**
1. Запустить сервер на компьютере
2. На Android открыть браузер Chrome
3. Зайти на адрес компьютера (например, `http://192.168.1.100:8000`)
4. В меню браузера выбрать "Добавить на главный экран"

## 📊 Основные рабочие сценарии

### 1. Поступил новый заказ
1. Зарегистрировать заказ в системе (указать устройство, местоположение, срок)
2. После получения акта дефектации - загрузить его
3. На основе дефектации система создаст список требуемых материалов
4. Проверить наличие на складе
5. Заказать недостающее у поставщиков
6. Проверить наличие денег на субсчете
7. При необходимости - отправить командировку

### 2. Отправка сотрудника в командировку
1. Проверить наличие средств на субсчете
2. Создать командировку в системе
3. Система напомнит о необходимости оформления служебки в HR
4. При продлении - автоматически обновить даты

### 3. Контроль дефицита материалов
1. Система автоматически отслеживает дефицит
2. Показывает предупреждения на дашборде
3. Можно сформировать отчет по дефициту
4. Увидеть какие заказы затронуты

### 4. Формирование документов
1. Выбрать заказ
2. Нажать "Сгенерировать акт приемки"
3. Система заполнит все данные автоматически
4. Проверить и сохранить
5. Распечатать, подписать, отсканировать
6. Загрузить скан обратно в систему

### 5. Запрос доплаты
1. Система показывает дефицит средств на контракте
2. Сгенерировать письмо о доплате (заполняется автоматически)
3. Отправить заказчику
4. Зарегистрировать в переписке

## 🔍 Быстрый поиск информации

Менеджер проекта может быстро ответить на вопросы:

**"Где сейчас наши люди в командировках?"**
→ Раздел "Командировки" → Вкладка "Карта"

**"Какой дефицит материалов по контракту?"**
→ Раздел "Комплектующие" → Вкладка "Дефицит"

**"Сколько денег осталось на контракте?"**
→ Раздел "Контракты" → Выбрать контракт → Просмотр дашборда

**"Какие заказы нужно выполнить срочно?"**
→ Раздел "Заказы" (отсортировано по приоритету)

**"Когда истекает срок по заказу?"**
→ Раздел "Заказы" → Столбец "Срок"

**"Где хранится бумажный документ?"**
→ Раздел "Документы" → Столбец "Место хранения"

4. **При поступлении оплат:**
   - Сразу регистрировать в системе
   - Обновлять данные от бухгалтерии

5. **Резервное копирование:**
   - Копировать файл service_contracts.db
   - Копировать папки uploads/, scans/, documents/
