# RSI + StochRSI Multi-Timeframe Trading Strategy

Торговая стратегия для TradingView, использующая комбинацию RSI и StochRSI индикаторов на разных таймфреймах.

## Логика стратегии

### Сигналы для лонга (длинной позиции):
- **Трендовый фильтр**: RSI на 4-часовом таймфрейме > 50 (восходящий тренд)
- **Сигнал входа**: StochRSI на 15-минутном таймфрейме пересекает уровень 25 снизу вверх
- **Сигнал выхода**: StochRSI на 15-минутном таймфрейме пересекает уровень 80 сверху вниз

### Сигналы для шорта (короткой позиции):
- **Трендовый фильтр**: RSI на 4-часовом таймфрейме < 50 (нисходящий тренд)
- **Сигнал входа**: StochRSI на 15-минутном таймфрейме пересекает уровень 75 сверху вниз
- **Сигнал выхода**: StochRSI на 15-минутном таймфрейме пересекает уровень 20 снизу вверх

### Улучшение сигналов дивергенциями:
- **Бычья дивергенция**: Повышает вероятность лонг-сигналов при RSI > 60
- **Медвежья дивергенция**: Повышает вероятность шорт-сигналов при RSI < 40

## Параметры индикаторов

- **RSI Length**: 8 периодов
- **StochRSI Length**: 5 периодов
- **StochRSI K Smooth**: 3 периода
- **StochRSI D Smooth**: 3 периода

## Установка и использование

1. Скопируйте код из файла `rsi_stochrsi_strategy.pine`
2. Откройте TradingView и создайте новый Pine Script индикатор
3. Вставьте код в редактор
4. Сохраните индикатор с именем "RSI + StochRSI Strategy"
5. Добавьте индикатор на график для тестирования

## Визуальные элементы

- **Синяя линия**: RSI на 4-часовом таймфрейме
- **Черная линия**: StochRSI K на 15-минутном таймфрейме
- **Фиолетовая линия**: StochRSI D на 15-минутном таймфрейме
- **Зеленые стрелки вверх**: Сигналы на покупку (LONG+ с дивергенцией)
- **Красные стрелки вниз**: Сигналы на продажу (SHORT+ с дивергенцией)
- **Зеленые треугольники**: Бычьи дивергенции
- **Красные треугольники**: Медвежьи дивергенции

## Риск-менеджмент

- Рекомендуется использовать не более 10% капитала на одну сделку
- Устанавливайте стоп-лосс в соответствии с вашим планом риск-менеджмента
- Тестируйте стратегию на исторических данных перед использованием на реальном счете

## Примечания

- Стратегия работает лучше на волатильных инструментах
- Рекомендуется использовать на основных валютных парах и индексах
- Перед использованием протестируйте на различных таймфреймах и инструментах
