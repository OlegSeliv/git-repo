## Введение

Система управления сервисными контрактами - это комплексное решение для оптимизации работы менеджера проекта, обеспечивающее:

- Полный контроль над выполнением сервисных контрактов
- Учет материалов и комплектующих
- Управление командировками сотрудников
- Финансовый контроль и учет платежей
- Автоматизацию документооборота
- Аналитику и отчетность в режиме реального времени

## Установка и настройка

### Системные требования

**Для сервера (Windows):**
- Windows 10/11 или Windows Server 2016+
- Python 3.8 или выше
- Node.js 16 или выше
- 4 ГБ оперативной памяти
- 10 ГБ свободного места на диске

**Для мобильного устройства (Android):**
- Android 7.0 (API level 24) или выше
- 2 ГБ оперативной памяти
- 100 МБ свободного места

### Установка серверной части

1. **Установка backend:**
```bash
cd service-contract-manager/backend
pip install -r requirements.txt
python main.py
```
Сервер запустится на порту 8000.

2. **Установка frontend:**
```bash
cd service-contract-manager/frontend
npm install
npm start
```
Веб-интерфейс будет доступен по адресу http://localhost:3000

### Установка мобильного приложения

1. **Подготовка среды разработки:**
   - Установите Android Studio
   - Настройте эмулятор или подключите устройство

2. **Сборка приложения:**
```bash
cd service-contract-manager/mobile
npm install
npx react-native run-android
```

3. **Установка APK:**
   - Готовый APK файл можно установить непосредственно на устройство
   - Разрешите установку из неизвестных источников в настройках

## Основные модули системы

### Главная панель (Dashboard)

Предоставляет общий обзор состояния всех контрактов и заказов:

- **Виджеты статистики:** количество активных контрактов, заказов, командировок
- **Финансовая сводка:** общая стоимость контрактов, полученные платежи, задолженности
- **Критические материалы:** список материалов с дефицитом
- **График командировок:** текущие и планируемые командировки
- **Уведомления:** важные события, требующие внимания

## Работа с контрактами

### Создание нового контракта

1. Перейдите в раздел "Контракты"
2. Нажмите кнопку "Новый контракт"
3. Заполните обязательные поля:
   - Номер контракта
   - Наименование заказчика
   - Даты начала и окончания
   - Общая стоимость
   - Сумма аванса

### Контроль финансового состояния

Система автоматически отслеживает:
- Поступление авансовых платежей
- Окончательные расчеты
- Баланс по каждому контракту
- Необходимость дополнительного финансирования

### Генерация писем о дефиците средств

При недостатке средств:
1. Откройте детали контракта
2. Нажмите "Сформировать письмо о дефиците"
3. Система автоматически создаст письмо с расчетами
4. Отредактируйте при необходимости и сохраните

## Управление заказами

### Создание заказа

1. Выберите контракт
2. Нажмите "Добавить заказ"
3. Укажите:
   - Номер заказа
   - Описание работ
   - Место выполнения
   - Плановые сроки
   - Серийный номер устройства (если применимо)

### Отслеживание статуса

Заказы проходят следующие стадии:
- **Новый** - заказ создан, работы не начаты
- **В работе** - выполнение работ
- **Ожидание материалов** - приостановлен из-за отсутствия комплектующих
- **Завершен** - работы выполнены, акты подписаны

### Привязка материалов к заказу

1. Откройте детали заказа
2. Перейдите на вкладку "Материалы"
3. Добавьте необходимые материалы из справочника
4. Укажите требуемое количество
5. Система проверит наличие и зарезервирует материалы

## Учет материалов

### Складской учет

Для каждого материала отслеживается:
- Текущий остаток на складе
- Зарезервированное количество
- Минимальный остаток
- Поставщик и срок поставки

### Контроль дефицита

Система автоматически:
- Выявляет материалы с критическим остатком
- Показывает дефицит для выполнения заказов
- Рассчитывает необходимое количество для закупки
- Формирует заявки на поставку

### Работа с актами дефектации

1. Загрузите акт дефектации в систему
2. На основе акта создайте список требуемых материалов
3. Система автоматически:
   - Проверит наличие материалов
   - Создаст заявки на недостающие позиции
   - Зарезервирует имеющиеся материалы

## Командировки

### Планирование командировки

1. Создайте новую командировку
2. Укажите:
   - ФИО сотрудника
   - Место командировки
   - Даты начала и окончания
   - Привязку к заказу
   - Тип транспорта и проживание

### Продление командировки

При необходимости продления:
1. Откройте активную командировку
2. Нажмите "Продлить"
3. Укажите новую дату окончания
4. Система сформирует служебную записку

### Контроль расходов

- Планируемые расходы вносятся при создании
- Фактические расходы обновляются по возвращении
- Автоматический расчет перерасхода/экономии

## Финансовый учет

### Регистрация платежей

1. Перейдите в раздел "Финансы"
2. Выберите "Новая транзакция"
3. Укажите:
   - Тип операции (аванс/окончательный расчет)
   - Сумму
   - Дату платежа
   - Номер платежного документа

### Проверка субсчета

Перед выполнением работ:
1. Откройте финансовый статус контракта
2. Проверьте баланс субсчета
3. При недостатке средств сформируйте письмо заказчику

### Финансовая отчетность

Доступны следующие отчеты:
- Общая финансовая сводка
- Детализация по контракту
- История платежей
- Прогноз поступлений

## Документооборот

### Загрузка документов

1. Выберите тип документа
2. Привяжите к контракту/заказу
3. Загрузите файл
4. Укажите место хранения бумажного оригинала

### Сканирование документов

1. Отсканируйте подписанный документ
2. Загрузите скан к соответствующей записи
3. Система сохранит связь между электронной версией и сканом

### Автоматическая генерация документов

Система может автоматически создавать:
- Акты выполненных работ
- Акты технической приемки
- Письма о дефиците средств
- Отчеты по материалам
- Графики командировок

### Поиск документов

Используйте фильтры для быстрого поиска:
- По типу документа
- По контракту
- По заказу
- По дате
- По статусу

## Отчетность и аналитика

### Доступные отчеты

1. **Сводный дашборд** - общее состояние всех контрактов
2. **Отчет по контракту** - детальная информация по выбранному контракту
3. **Анализ материалов** - состояние склада и прогноз потребностей
4. **График командировок** - загрузка сотрудников
5. **Финансовая аналитика** - движение средств, прогнозы

### Экспорт отчетов

Все отчеты можно экспортировать в:
- Excel (для дальнейшей обработки)
- PDF (для печати и архива)
- Word (для редактирования)

## Мобильное приложение

### Возможности

Мобильное приложение позволяет:
- Просматривать статус контрактов и заказов
- Проверять наличие материалов
- Отслеживать командировки
- Получать уведомления о важных событиях
- Просматривать документы

### Настройка подключения

1. Откройте настройки приложения
2. Укажите IP-адрес сервера
3. Введите порт (по умолчанию 8000)
4. Сохраните настройки

### Работа в офлайн-режиме

Приложение кэширует основные данные для работы без подключения:
- Список контрактов и заказов
- Справочник материалов
- Последние просмотренные документы

## Организация бумажного документооборота

### Рекомендуемая структура папок

```
📁 Документы/
├── 📁 Контракты/
│   ├── 📁 [Номер контракта]/
│   │   ├── 📁 Основной договор/
│   │   ├── 📁 Дополнительные соглашения/
│   │   ├── 📁 Переписка/
│   │   └── 📁 Финансовые документы/
├── 📁 Заказы/
│   ├── 📁 [Год]/
│   │   └── 📁 [Месяц]/
│   │       └── 📁 [Номер заказа]/
│   │           ├── 📁 Техническая документация/
│   │           ├── 📁 Акты/
│   │           └── 📁 Накладные/
├── 📁 Акты/
│   ├── 📁 Дефектации/
│   ├── 📁 Технической приемки/
│   ├── 📁 Сдачи-приемки работ/
│   └── 📁 Удостоверения военпреда/
├── 📁 Командировки/
│   └── 📁 [ФИО сотрудника]/
│       ├── 📁 Приказы/
│       ├── 📁 Отчеты/
│       └── 📁 Авансовые отчеты/
├── 📁 Материалы/
│   ├── 📁 Накладные/
│   ├── 📁 Счета-фактуры/
│   └── 📁 Акты приемки/
└── 📁 Протоколы совещаний/
    └── 📁 [Год]/
        └── 📁 [Месяц]/
```

### Правила именования файлов

Рекомендуется использовать следующий формат:

`[ТипДокумента]_[НомерКонтракта]_[НомерЗаказа]_[Дата]_[Описание]`

Примеры:
- `АКТ_К-2023-001_З-045_20231215_Выполненные_работы.pdf`
- `ПИСЬМО_К-2023-001_20231215_Запрос_доп_финансирования.pdf`
- `ПРОТОКОЛ_20231215_Совещание_по_контракту_К-2023-001.pdf`

### Связь электронных и бумажных документов

1. При загрузке документа в систему указывайте место хранения оригинала
2. Используйте штрих-коды или QR-коды для быстрого поиска
3. Ведите журнал выдачи оригиналов документов

2. Проверка выполнения задач
3. Планирование на следующий день
4. Формирование отчетов при необходимости

### Еженедельные задачи

**Понедельник:**
- Анализ выполнения контрактов за прошлую неделю
- Планирование командировок на неделю
- Проверка финансового состояния контрактов

**Среда:**
- Контроль поставок материалов
- Актуализация складских остатков
- Формирование заявок на закупку

**Пятница:**
- Подготовка недельного отчета
- Проверка документооборота
- Архивирование завершенных документов

### Использование уведомлений

Настройте уведомления для критических событий:
- Окончание срока контракта (за 30 дней)
- Критический уровень материалов
- Окончание командировки (за 3 дня)
- Просроченные задачи
- Поступление платежей

## Решение типовых задач

### Срочный заказ с выездом в регион

1. Создайте заказ с приоритетом "Срочный"
2. Проверьте наличие материалов
3. При наличии материалов - создайте командировку
4. При дефиците - сформируйте срочную заявку поставщику
5. Оформите служебную записку на командировку
6. Отслеживайте выполнение через мобильное приложение

### Недостаток средств на контракте

1. Откройте финансовый статус контракта
2. Сформируйте отчет о расходах
3. Создайте письмо о необходимости доплаты
4. Приложите расчеты и обоснование
5. Отправьте заказчику и зафиксируйте в системе

### Контроль множественных командировок

1. Используйте календарный вид в разделе "Командировки"
2. Настройте уведомления об окончании
3. Контролируйте пересечения и конфликты
4. Используйте мобильное приложение для оперативной связи

## Контрольные вопросы для проверки готовности

Менеджер должен быть способен быстро ответить на следующие вопросы:

1. **Какой общий статус по всем контрактам?**
   → Смотрите главный дашборд

2. **Где сейчас находятся наши сотрудники?**
   → Раздел "Командировки" - активные

3. **Какие материалы в дефиците?**
   → Дашборд - критические материалы

4. **Сколько денег осталось на контракте X?**
   → Контракты - финансовый статус

5. **Какие устройства сейчас на ремонте?**
   → Дашборд - устройства на заводе

6. **Какие заказы просрочены?**
   → Заказы - фильтр по статусу "Просрочен"

7. **Когда последний платеж по контракту?**
   → Финансы - история транзакций

8. **Где хранится оригинал акта?**
   → Документы - поиск - место хранения

## Заключение

Система управления сервисными контрактами позволяет:

- Сократить время на рутинные операции на 60-70%
- Исключить потерю важной информации
- Обеспечить прозрачность всех процессов
- Предотвратить срывы сроков из-за дефицита материалов
- Оптимизировать финансовые потоки
- Улучшить качество обслуживания заказчиков

При правильном использовании система становится незаменимым инструментом менеджера проекта, обеспечивая полный контроль над выполнением сервисных контрактов.
