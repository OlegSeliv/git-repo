# Быстрый старт - Система управления сервисными контрактами

## 🚀 Запуск за 5 минут

### Шаг 1: Установка зависимостей

#### Backend (в терминале Windows):
```bash
cd service-contract-manager\backend
pip install -r requirements.txt
```

#### Frontend (в другом терминале):
```bash
cd service-contract-manager\frontend
npm install
```

### Шаг 2: Запуск системы

#### Запуск сервера API:
```bash
cd service-contract-manager\backend
python main.py
```
✅ Сервер запущен на http://localhost:8000

#### Запуск веб-интерфейса:
```bash
cd service-contract-manager\frontend
npm start
```
✅ Интерфейс доступен на http://localhost:3000

### Шаг 3: Первый вход
Откройте браузер и перейдите на http://localhost:3000

## 🎯 Первые шаги в системе

### 1. Создайте первый контракт:
- Перейдите в раздел "Контракты"
- Нажмите "Новый контракт"
- Заполните основные данные

### 2. Добавьте материалы на склад:
- Перейдите в "Материалы и склад"
- Нажмите "Добавить материал"
- Внесите номенклатуру

### 3. Создайте заказ:
- Откройте созданный контракт
- Нажмите "Добавить заказ"
- Укажите детали работ

### 4. Проверьте дашборд:
- Вернитесь на главную страницу
- Увидите обновленную статистику

## 🆘 Решение проблем

### Сервер не запускается:
- Проверьте, свободен ли порт 8000
- Убедитесь, что Python установлен корректно

### Frontend не открывается:
- Проверьте, установлен ли Node.js
- Попробуйте очистить кэш: `npm cache clean --force`

### База данных не создается:
- Убедитесь, что у вас есть права на запись в папку
- Удалите файл `service_contracts.db` и перезапустите

## 📞 Полезные команды

### Проверка статуса:
```bash
# Проверить запущенные процессы
netstat -an | findstr :8000
netstat -an | findstr :3000
```

### Остановка серверов:
- Backend: `Ctrl + C` в терминале
- Frontend: `Ctrl + C` в терминале

### Очистка и переустановка:
```bash
# Backend
pip uninstall -r requirements.txt -y
pip install -r requirements.txt

# Frontend
rd /s /q node_modules
npm install
```
