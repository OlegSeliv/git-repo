# Система управления сервисными контрактами

## Описание
Комплексная система для управления сервисными контрактами, включающая учет заказов, материалов, командировок, финансов и документооборота.

## Компоненты системы

### 1. Backend (Python/FastAPI)
- REST API для всех операций
- SQLite база данных для локального хранения
- Система управления документами
- Генерация отчетов

### 2. Frontend (React)
- Веб-интерфейс для Windows
- Полнофункциональная панель управления
- Работа с документами и отчетами

### 3. Mobile (React Native)
- Мобильное приложение для Android
- Просмотр статуса контрактов
- Управление командировками
- Доступ к документам

## Основные модули

1. **Управление контрактами** - учет всех сервисных контрактов и заказов
2. **Складской учет** - отслеживание материалов и комплектующих
3. **Командировки** - планирование и контроль командировок сотрудников
4. **Финансовый учет** - контроль оплат, авансов и расчетов
5. **Документооборот** - хранение и управление документами
6. **Отчетность** - аналитика и дашборды

## Установка и запуск

### Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```

### Frontend
```bash
cd frontend
npm install
npm start
```

### Mobile
```bash
cd mobile
npm install
npx react-native run-android
```
