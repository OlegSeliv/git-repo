# RSI + StochRSI Trading Bot для TradingView

## Описание

Торговый робот на Pine Script v5, который использует комбинацию индикаторов RSI и StochRSI для генерации торговых сигналов. Стратегия основана на мультитаймфреймовом анализе с дополнительным фильтром дивергенций.

## Логика торговли

### Сигналы для лонга (покупки):
- **Основное условие**: RSI на 4-часовом таймфрейме > 50
- **Вход**: Пересечение StochRSI на 15-минутном таймфрейме уровня 25 снизу вверх
- **Выход**: Пересечение StochRSI на 15-минутном таймфрейме уровня 80 сверху вниз
- **Дополнительный фильтр**: Наличие бычьей дивергенции (опционально)

### Сигналы для шорта (продажи):
- **Основное условие**: RSI на 4-часовом таймфрейме < 50
- **Вход**: Пересечение StochRSI на 15-минутном таймфрейме уровня 75 сверху вниз
- **Выход**: Пересечение StochRSI на 15-минутном таймфрейме уровня 20 снизу вверх
- **Дополнительный фильтр**: Наличие медвежьей дивергенции (опционально)

## Настройки стратегии

### StochRSI параметры:
- **RSI Length**: 8 (длина периода RSI)
- **Stochastic Length**: 5 (длина периода Stochastic)
- **Smooth K**: 3 (сглаживание линии K)
- **Smooth D**: 3 (сглаживание линии D)

### Уровни входа/выхода:
- **StochRSI Long Entry Level**: 25
- **StochRSI Long Exit Level**: 80
- **StochRSI Short Entry Level**: 75
- **StochRSI Short Exit Level**: 20

### RSI фильтр:
- **RSI Filter Length**: 14
- **RSI Filter Level**: 50

### Настройки дивергенции:
- **Enable Divergence Filter**: включить/выключить фильтр дивергенций
- **Divergence Lookback Period**: 10 (период поиска дивергенций)

### Отображение:
- **Show Entry/Exit Signals**: показать сигналы входа/выхода на графике
- **Show StochRSI Levels**: показать уровни StochRSI

## Установка и использование

1. Откройте TradingView
2. Перейдите в Pine Editor
3. Скопируйте код из файла `rsi_stochrsi_trading_bot.pine`
4. Вставьте код в редактор
5. Нажмите "Add to Chart"
6. Настройте параметры в соответствии с вашими предпочтениями

## Визуальные элементы

### Сигналы на графике:
- 🔺 **Зеленый треугольник вверх**: сигнал входа в лонг
- 🔻 **Красный треугольник вниз**: сигнал входа в шорт
- ❌ **Оранжевый крест**: сигнал выхода из позиции

### Дивергенции:
- 💎 **Зеленый ромб**: бычья дивергенция
- 💎 **Фиолетовый ромб**: медвежья дивергенция

### Информационная панель:
Отображает текущие значения:
- RSI 4H и его статус (Bullish/Bearish)
- StochRSI K 15m и его уровень (High/Low)
- Текущая позиция (Long/Short/None)
- Статус дивергенции (если включен фильтр)

### Цветовой фон:
- **Зеленый фон**: RSI 4H > 50 (бычий тренд)
- **Красный фон**: RSI 4H < 50 (медвежий тренд)

## Алерты

Стратегия поддерживает следующие алерты:
- Long Entry Alert
- Short Entry Alert
- Long Exit Alert
- Short Exit Alert

## Рекомендации по использованию

1. **Тестирование**: Обязательно протестируйте стратегию на исторических данных
2. **Риск-менеджмент**: Используйте стоп-лоссы и управление размером позиции
3. **Таймфреймы**: Рекомендуется использовать на таймфреймах от 1 часа и выше
4. **Волатильность**: Стратегия лучше работает на волатильных рынках
5. **Дивергенции**: Включение фильтра дивергенций может улучшить качество сигналов, но уменьшить их количество

## Ограничения

- Стратегия может давать ложные сигналы в боковом тренде
- Требует подтверждения другими методами анализа
- Не учитывает фундаментальные факторы
- Может быть чувствительна к настройкам параметров

## Дополнительные возможности

Вы можете модифицировать стратегию:
- Добавить дополнительные фильтры (объем, ATR и т.д.)
- Изменить логику управления позициями
- Добавить трейлинг стоп
- Интегрировать с другими индикаторами
