# 🎯 НАЧНИТЕ ЗДЕСЬ!

## Добро пожаловать в систему управления сервисными контрактами!

Эта система создана специально для оптимизации работы менеджера сервисных проектов.

---

## ⚡ Быстрый старт (5 минут)

### Шаг 1: Установите Python
- **Windows**: https://python.org → скачать и установить
- **Linux**: уже установлен
- **Android**: установить Termux из F-Droid

### Шаг 2: Установите зависимости
```bash
pip install -r requirements.txt
```

### Шаг 3: Добавьте примерные данные (опционально)
```bash
python sample_data.py
```

### Шаг 4: Запустите систему

**Windows:**
```cmd
start_windows.bat
```

**Linux/Mac:**
```bash
./start_linux.sh
```

**Android (Termux):**
```bash
python backend.py
```

### Шаг 5: Откройте в браузере
```
http://localhost:8000
```

## 🎓 Как использовать

### Типичный рабочий день менеджера

**Утро (9:00):**
1. Открыть дашборд
2. Проверить предупреждения
3. Посмотреть срочные заказы

**В течение дня:**
- Регистрировать новые заказы
- Контролировать дефицит материалов
- Планировать командировки
- Генерировать документы
- Отвечать на вопросы начальника

**Вечер (17:00):**
- Обновить статусы
- Сформировать отчеты
- Спланировать завтра

### Примеры использования

#### 📝 Поступил новый заказ
```
1. Раздел "Заказы" → "+ Новый заказ"
2. Заполнить форму
3. Дождаться акта дефектации
4. Загрузить в "Документы"
5. Система создаст заявку на материалы
6. При необходимости - отправить командировку
```

#### 📊 Нужен отчет для бухгалтерии
```
1. Раздел "Контракты"
2. Выбрать контракт
3. Кнопка "Скачать отчет по оплатам"
4. Получить готовый Excel файл
```

#### ⚠️ Обнаружен дефицит материалов
```
1. Дашборд покажет предупреждение
2. Раздел "Комплектующие" → "Дефицит"
3. Увидеть что не хватает
4. Заказать у поставщика
5. Если критично - уведомить начальника
```

#### ✈️ Отправить в командировку
```
1. Проверить наличие денег на контракте
2. Раздел "Командировки" → "+ Новая"
3. Выбрать сотрудника, место, даты
4. Система напомнит оформить служебку
5. При продлении - обновить даты
```

#### 📄 Сформировать акт приемки
```
1. Раздел "Заказы" → Выбрать завершенный
2. "Сгенерировать акт приемки"
3. Система заполнит ВСЕ данные автоматически
4. Скачать Word файл
5. Распечатать, подписать, отсканировать
6. Загрузить скан обратно
```

## 🆘 Помощь

### Система не запускается?

**Проблема:** "Python не найден"
```bash
# Установите Python с python.org
# При установке отметьте "Add Python to PATH"
```

**Проблема:** "Ошибки при установке библиотек"
```bash
# Обновите pip
python -m pip install --upgrade pip
# Попробуйте снова
pip install -r requirements.txt
```

**Проблема:** "Порт 8000 занят"
```bash
# Измените порт в backend.py на 8001
# Или закройте приложение, использующее порт 8000
```
