# 📊 Обзор проекта: Система управления сервисными контрактами

## Что создано

Полнофункциональная система для управления сервисными контрактами с возможностью работы на Windows и Android.

## 📦 Компоненты системы

### 1. База данных (database.py)

**SQLite база данных** с 14 основными таблицами:

- ✅ Контракты и субсчета
- ✅ Заказы на выполнение работ
- ✅ Комплектующие и материалы
- ✅ Требования материалов для заказов
- ✅ Поставщики и заказы поставщикам
- ✅ Сотрудники
- ✅ Командировки
- ✅ Платежи (авансирование и окончательный расчет)
- ✅ Документы с привязкой сканов
- ✅ Протоколы совещаний
- ✅ Задачи из протоколов
- ✅ Переписка
- ✅ Акты дефектации

**Особенности:**
- Полная нормализация данных
- Индексы для быстрого поиска
- Каскадные связи между таблицами
- Автоматические метки времени

### 2. Backend API (backend.py + api_extended.py)

**REST API на FastAPI** с 50+ эндпоинтами:

#### Основные группы API:

**Контракты:**
- GET /api/contracts - список всех контрактов
- GET /api/contracts/{id} - детали контракта
- POST /api/contracts - создать контракт
- PUT /api/contracts/{id} - обновить контракт
- GET /api/contracts/{id}/dashboard - дашборд контракта

**Заказы:**
- GET /api/work-orders - список заказов
- POST /api/work-orders - создать заказ
- GET /api/work-orders/{id} - детали заказа с компонентами
- PUT /api/work-orders/{id}/status - обновить статус

**Комплектующие:**
- GET /api/components - все комплектующие
- GET /api/components/deficit - дефицит материалов
- POST /api/components - добавить компонент

**Командировки:**
- GET /api/business-trips - список командировок
- POST /api/business-trips - создать командировку
- PUT /api/business-trips/{id}/extend - продлить командировку
- GET /api/business-trips/map - карта командировок

**Платежи:**
- GET /api/payments - список платежей
- POST /api/payments - зарегистрировать платеж
- GET /api/payments/balance/{contract_id} - баланс контракта

**Документы:**
- GET /api/documents - список документов
- POST /api/documents - создать документ
- POST /api/documents/{id}/upload-scan - загрузить скан
- GET /api/documents/{id}/download-scan - скачать скан

**Протоколы:**
- GET /api/meeting-protocols - список протоколов
- POST /api/meeting-protocols - создать протокол
- GET /api/protocol-tasks - задачи из протоколов

**Аналитика:**
- GET /api/analytics/overview - общая аналитика

#### Расширенные функции (api_extended.py):

**Генерация документов:**
- POST /api/extended/generate/acceptance-act - акт сдачи-приемки
- POST /api/extended/generate/military-certificate - удостоверение военпреда
- POST /api/extended/generate/payment-request-letter - письмо о доплате

**Excel отчеты:**
- GET /api/extended/reports/payment-tracking/{contract_id} - учет оплат
- GET /api/extended/reports/components-deficit - дефицит комплектующих
- GET /api/extended/reports/trips-schedule - график командировок

**Быстрые запросы для менеджера:**
- GET /api/extended/quick/budget-status/{contract_id} - состояние бюджета
- GET /api/extended/quick/deficit-alert - предупреждение о дефиците
- GET /api/extended/quick/trips-now - где сейчас сотрудники
- GET /api/extended/quick/urgent-orders - срочные заказы
- GET /api/extended/quick/manager-dashboard - полный дашборд

### 3. Frontend интерфейс (frontend.html)

**Современный веб-интерфейс** с адаптивным дизайном:

#### Основные разделы:

1. **Главный дашборд**
   - Статистика по контрактам
   - Выполненные заказы
   - Активные командировки
   - Финансовый баланс

2. **Контракты**
   - Список всех контрактов
   - Детальная информация
   - Финансовый баланс
   - Связанные заказы

3. **Заказы**
   - Все заказы с приоритетами
   - Статусы выполнения
   - Сроки и местоположение
   - Детали по каждому заказу

4. **Комплектующие**
   - Список всех материалов
   - Вкладка "Дефицит" с предупреждениями
   - Остатки на складе
   - Заказанные материалы

5. **Командировки**
   - Активные и запланированные
   - Карта размещения сотрудников
   - Продление командировок

6. **Платежи**
   - Все платежи по контрактам
   - Статусы оплат
   - Финансовый баланс

7. **Документы**
   - Централизованное хранилище
   - Привязка к контрактам/заказам
   - Сканы документов
   - Места хранения бумажных копий

8. **Протоколы**
   - Протоколы совещаний
   - Задачи с дедлайнами
   - Контроль выполнения

9. **Аналитика**
   - Сводная статистика
   - Графики и диаграммы
   - Отчеты для экспорта

**Особенности UI:**
- 📱 Адаптивный дизайн (работает на мобильных)
- 🎨 Современная цветовая схема
- ⚡ Быстрая навигация
- 🔍 Поиск и фильтрация
- 📊 Визуализация данных
- ⚠️ Предупреждения и алерты

### 4. Генератор документов (document_generator.py)

**Автоматическое создание документов** на основе шаблонов:

#### Поддерживаемые документы:

1. **Акт сдачи-приемки выполненных работ**
   - Автозаполнение из данных заказа
   - Список использованных материалов
   - Таблица компонентов
   - Подписи сторон

2. **Удостоверение военпреда**
   - Данные заказа
   - Информация о контракте
   - Подтверждение выполнения

3. **Письмо о необходимости доплаты**
   - Анализ финансового состояния
   - Расчет дефицита средств
   - Обоснование запроса

**Формат:** Microsoft Word (.docx)

**Процесс:**
1. Система собирает данные из БД
2. Заполняет шаблон
3. Создает документ
4. Регистрирует в базе документов
5. Пользователь проверяет и подписывает
6. Загружает скан обратно

### 5. Менеджер Excel отчетов (excel_manager.py)

**Создание аналитических таблиц** для бухгалтерии и управления:

#### Типы отчетов:

1. **Таблица учета оплат vs выполненных работ**
   - Все заказы с ценами
   - Все платежи
   - Финансовый баланс
   - Цветовая индикация

2. **Отчет по дефициту комплектующих**
   - Требуется / На складе / Дефицит
   - Затронутые заказы
   - Стоимость дефицита
   - Приоритизация по срочности

3. **График командировок**
   - Расписание по сотрудникам
   - Местоположение
   - Сроки пребывания
   - Связь с заказами

**Формат:** Microsoft Excel (.xlsx)

**Особенности:**
- Профессиональное форматирование
- Цветовые схемы
- Автоподбор ширины столбцов
- Формулы и расчеты

## 🔧 Технологический стек

### Backend:
- **Python 3.8+**
- **FastAPI** - современный веб-фреймворк
- **SQLite** - встроенная база данных
- **Uvicorn** - ASGI сервер
- **Pydantic** - валидация данных
- **python-docx** - генерация Word документов
- **openpyxl** - работа с Excel
- **pandas** - обработка данных

### Frontend:
- **HTML5**
- **CSS3** (с градиентами и анимациями)
- **JavaScript** (Vanilla JS, без фреймворков)
- **Fetch API** для работы с backend

### База данных:
- **SQLite 3**
- 14 таблиц
- Нормализованная структура
- Индексы для производительности
